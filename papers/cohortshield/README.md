# CohortShield

Reproducibility package for **Release Timing as a Quasi-Identifier: Event-Aware Disclosure Control for Anonymous Narratives in Small Communities**.

The study uses only synthetic data. It does not contain student records, submissions, names, or any other real-world personal data.

## Contents

- `main.tex`: Springer Nature-format manuscript source.
- `experiment.py`: deterministic population, narrative, policy, analysis, and figure generator.
- `verify_results.py`: independent integrity checks for the aggregate results.
- `verify_manuscript.py`: checks quantitative claims in the manuscript against machine-readable outputs.
- `results/summary_by_seed.csv`: 1,350 replicate-level aggregate rows.
- `results/headline_stats.json`: primary results and replicate-bootstrap intervals.
- `figures/`: vector PDF figures generated by the experiment.

Narrative-level rows are intentionally not persisted. They are regenerated in memory from the master seed and immediately aggregated, limiting both disk writes and the risk that a synthetic artifact is mistaken for source data.

## Reproduce the analysis

The verified run used Python 3.9.6, NumPy 2.0.2, pandas 2.3.3, and Matplotlib 3.9.4.

```bash
python experiment.py
python verify_results.py
python verify_manuscript.py
```

The full robustness matrix evaluates 135,000 synthetic narratives and may take several minutes on a laptop.

## Build the manuscript

Download the current Springer Nature LaTeX authoring template from the [official Springer Nature author-support page](https://www.springernature.com/gp/authors/campaigns/latex-author-support). Place `sn-jnl.cls`, `main.tex`, and the four figure PDFs in one build directory, then run:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

The journal selected at submission may require a different `sn-jnl` reference-style option. The manuscript currently uses the numbered math-and-physical-sciences style as a journal-neutral Springer Nature submission format.

## Interpretation boundary

CohortShield's candidate-set guarantee is conditional on the auxiliary information declared to the model. The zero-mismatch simulation verifies that conditional guarantee. The hidden-clue scenarios deliberately show its failure under omitted attacker knowledge; the method must not be described as proving that a deployed service is anonymous.
